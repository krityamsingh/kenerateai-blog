## Alternatives & comparisons
Keep pages objective and useful.
Include:
- who each tool is best for
- model/workflow differences
- access/pricing model
- output/editing features
- limitations
- current date of comparison

Do not fabricate test results.

## FAQ / LLM query fan-out
Use concise first-sentence answers to full questions, followed by detail.
This makes passages easier to understand for humans, search engines and retrieval systems.

## Metadata
Do not put all 300+ keywords in every title/description.
Use `metadata-page-map.csv` as the page-level mapping.
The HTML template includes 100 core terms in `meta keywords` only because it was specifically requested; Google does not use that tag as a modern ranking signal.
