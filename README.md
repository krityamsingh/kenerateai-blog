# KenerateAI Creator Lab

A lightweight, crawlable editorial site for KenerateAI creator education, SEO, GEO, AEO, and AI-search discovery.

## Included
- Semantic static HTML landing page and long-form 2026 discovery article
- `robots.txt` with permissive rules for major search/AI crawlers
- `llms.txt` machine-readable site guide
- `sitemap.xml`
- `vercel.json` headers and clean URL configuration

## Production
Canonical site: https://kenerateai-blog.vercel.app/

`llms.txt` is included as an agent navigation aid. It should not be treated as a Google ranking factor.
